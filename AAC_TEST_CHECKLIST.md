# Samy AAC Test Checklist

Use this checklist before publishing changes that touch vocabulary, layout, speech, or editing.

- Core words stay in the same physical slot across every folder: أنا, أنت, أريد, اذهب, توقف, مساعدة, المزيد, انتهيت, أكل, أشرب, أحب, أستطيع, نعم, لا.
- Only the top fringe/category section changes when switching folders.
- Arabic mode sets the page to RTL and the sentence bar reads Arabic in the order tapped.
- Speak reads the full selected message.
- Tapping a word adds it to the message and speaks that word.
- Delete stops speech and removes only the last word.
- Clear stops speech and clears the whole message.
- Child Mode hides editing tools and advanced controls.
- Favorites editing appears only in Customize/Edit mode.
- The الأسئلة folder includes ماذا, أين, من, متى, لماذا, كيف, هل, أي, كم.
- The طبي folder includes ألم, جائع, عطشان, الحمام, تعبان, مريض, دواء, طبيب, حرارة, طوارئ, ألم هنا, أحتاج مساعدة.
- Beginner shows fewer high-frequency words, Intermediate uses the 5x5 board, and Advanced reveals grammar, time, and phrase folders.
- Vocabulary items keep this replaceable symbol structure: id, arabicLabel, englishKey, category, symbol, colorType, isCore, position.
